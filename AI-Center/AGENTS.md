# 同一项目续作

1. 首先读 PROJECT_STATE.md、DEVELOPMENT_PROGRESS.md、TODO.md、BUILD_STATUS.md、CHANGELOG.md 和 USER_REQUIREMENTS.md。
2. 永远沿用 PROJECT_ID，禁止因会话、额度或环境问题重新生成重复工程。保留已有代码与已验证结果。
3. 用户是唯一管理员；默认生成副本，不覆盖原文件，不扩大文件授权，不静默付费或上传私人内容。
4. 先做完并验证 Phase 1，再按需求进入 Phase 2。不要把未完成功能做成空按钮。
5. 以实际编译、测试和 APK 产物报告进度。规则引擎、模板或固定答案不得冒充 LLM 推理；词法检索不得冒充向量检索。
6. 每批代码和构建后运行 scripts/checkpoint.py，更新五个状态文件并持久保存归档。脚本本身只创建本地归档，后续执行者必须再通过可用的正式文件保存能力保存。
7. 平台额度不足时保存并停止，不尝试绕过额度、网络或权限控制。新会话先恢复最近成功持久保存的归档。
8. 开发日志不得包含 API Key、管理员密码或用户文件内容。每次续作保留模型及依赖的真实版本与未完成事项。
