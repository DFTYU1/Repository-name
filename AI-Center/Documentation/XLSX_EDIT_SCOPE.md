# xlsx修改副本阶段

当前支持在已读取工作簿中修改一个已有单元格：文本、有限精度数值、FormulaCheck明确STRUCTURE_ONLY通过的单层函数公式。生成独立ZIP后由生产读取器复核目标值，保存到应用文件沙盒及文件目录，再由系统创建文档导出；导出后重新读取比对字节。默认不写原始URI。每次基于选中的原工作簿生成单格修改副本，不是累计多格编辑。

修改会保留样式索引与未修改ZIP部件内容；清空全部工作表普通公式的缓存，移除calcChain与对应关系/内容类型记录，并要求兼容Excel应用打开后全量重算。应用没有计算公式，不能证明新结果正确。暂拒绝共享/数组/数据表公式、外链/签名工作簿；不保证所有复杂Excel特性往返兼容。未绘制或编辑图表。原只读导入的大小/结构限制继续有效。

读取选择使用临时单URI只读权限；修改访问5分钟过期，断开/后台停止任务。导出由用户在系统创建文档选择器选择新副本目的地，写入与读回可取消；失败可能留下不完整目的文件，完整本地副本保留，不自动删除用户目的地。导出不是私有云盘上传成功证明。

主机新增28个断言PASS：原输入不变、Unicode/转义/文本公式不执行、精确数值、目标公式文本、缓存清除、calcChain清理、保留其他部件/样式、无效输入与取消。Android新增xlsx_copy_editor_and_ui强制门禁，待CI；验证生产编辑器及实际页面生成并读取沙盒副本。系统选择器/外部文档提供程序/真机完整链路仍NOT_RUN。

后续：实际文档提供程序全链路、复杂文件兼容、多格编辑、公式重算引擎、图表/Pareto/SPC、自动诊断与修复；这些未完成项不得标记为完成。
